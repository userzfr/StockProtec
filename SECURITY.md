## 🚨 Reporting a Vulnerability

Si vous découvrez une faille de sécurité dans **StockProtec**, merci de suivre la procédure ci-dessous :  

1. **Ne pas ouvrir d’issue publique** sur GitHub concernant la faille.  
2. Contactez directement l’auteur via **Discord** :  
   - Pseudo : `userz_fr`  
   - ID : `634442174305402883`  
3. Fournissez autant de détails que possible :  
   - Description du problème  
   - Étapes pour reproduire  
   - Impact potentiel (ex : fuite de données, exécution de code, etc.)  
   - Solutions temporaires possibles (si connues)  
4. Vous recevrez une réponse sous **7 jours ouvrés**.  
5. Les correctifs de sécurité seront intégrés dans la prochaine **release mineure ou patch**.  
6. Vous serez informé si la faille est confirmée, corrigée ou non retenue.
