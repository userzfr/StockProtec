# ⚡ QuickStart - StockProtec v5

## 1. Installer les dépendances

```bash
npm install
```

## 2. Lancer l'application

```bash
npm run dev:all
```

## 3. Accéder à l'interface

- Frontend : `http://localhost:5173`
- API : `http://localhost:3001`

## 4. Test rapide

- Créez un sac
- Rafraîchissez la page
- Vérifiez que le sac est toujours visible

## 5. Si vous préférez lancer séparément

```bash
npm run server
npm run dev
```

## 6. Vérifier le bon fonctionnement

- `npm run build`
- `npm run dev`
- `npm run server`

## 7. Versions supportées

- `v5.x` ✅
- Autres versions ❌ non supportées
