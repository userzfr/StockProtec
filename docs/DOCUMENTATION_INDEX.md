## 🎯 Vue d'ensemble du projet

StockProtec v5.2 est une application web moderne conçue pour la gestion complète du matériel et des stocks de la Protection Civile. L'application combine :

- **Frontend React** : Interface utilisateur moderne et responsive
- **Backend Node.js** : API REST sécurisée avec Express
- **Base de données SQLite** : Stockage local robuste et portable
- **Authentification sécurisée** : Gestion des utilisateurs avec rôles
- **Sauvegarde automatique** : Protection des données contre la perte

## 🚀 Démarrage rapide

```bash
# 1. Installation des dépendances
npm run setup

# 2. Démarrage en production
npm run prod
```

L'application sera accessible sur `http://localhost:5173`
